# bazis-cli 2.6.1

## Changes

- The evals grader keeps the settings of the machine (the database and GDAL) and creates
  the database on the server of the project.
- The check that the migrations apply does not pass silently: when the database server is
  unknown or createdb is missing, the check fails.
- The test of the requirements to the latest releases of bazis and bazis-mcp is restored.
