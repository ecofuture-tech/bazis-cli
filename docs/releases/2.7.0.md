# bazis-cli 2.7.0

## Features

- `bazis new --database host:port` chooses the PostgreSQL server of the project. Without it
  the server is that of `BS_DATABASES__DEFAULT__HOST` and `PORT` of the environment, else
  localhost:5432, as before. The server is named in `.env` before the database is made,
  whatever becomes of the database (the shared resolver of bazis-mcp 2.12,
  `project.database_server`).
- A refused server (`--database` not as `host:port`, or other than the one the environment
  sets) stops the command with `bazis: ...` and exit code 1, before anything is written.
- `--name` is normalized to an identifier as the name of the directory is: `bazis new shop
  --name master-na-chas` makes the package `master_na_chas`.

## Changes

- The evals build their projects on the server of the environment, else localhost:5432,
  through the same resolver.
- The help of `--language`, the README and the instructions of the package no longer say
  that English is always a language of the product: it has the language of the description
  or of `--language` alone, unless the description asks for more (bazis-mcp 2.10). The
  msgids of the code stay English.
- `test_new_with_a_language` expects the text of bazis-mcp 2.10 for the language of the
  product (the requirement is kept: the language of `--language` reaches the prompt and
  `project.env`).

## Requirements

- `bazis>=2.22.0`, `bazis-mcp>=2.12.0` (`database_server(default=)`, the package name from a
  string).

## Upgrading

- Nothing to change. A script that passed a name with hyphens to `--name` and got a refusal
  now gets the package with underscores.
