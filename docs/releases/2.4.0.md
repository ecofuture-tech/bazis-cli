# bazis-cli 2.4.0

The first release. Requires bazis-mcp 2.4.1 and the Claude Agent SDK.

The command `bazis`:

- `bazis new DIR DESCRIPTION` writes the skeleton of a Bazis project with its `.venv`, then
  the agent builds the apps the description needs with the Bazis packages it chooses;
- `bazis add PACKAGE [GOAL]` adds a Bazis package and sets it up;
- `bazis audit [--fix]` reviews the project against the guides and checks of its packages.

The agent edits the files of the project; every shell command and every other tool call is
shown and asked in the terminal (`--yes` allows them). It cannot read `.env` or commit,
push and reset with git, and only bazis-cli's own permissions and MCP server apply. Options: `--model` (default `claude-opus-5-5`), `--effort`,
`--budget`, `--name` (`new`).
